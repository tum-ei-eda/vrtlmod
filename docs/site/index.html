From RTL to experiment

Three steps.
A controllable fault.

vRTLmod instruments Verilator’s generated code. You keep your RTL sources and control the experiment from the simulation harness.

  1. 01

    Generate your model

    Use Verilator to translate your RTL into a C++ or SystemC model.

    RTL → Verilator → C++
  2. 02

    Add injection points

    Pass the generated sources and headers to vRTLmod. Get a rewritten model, a target inventory, and an injection API.

    vrtlmod --out=instrumented …
  3. 03

    Run the experiment

    Pick an injectable target, prepare a fault, arm it, and advance the simulation through the relevant state update.

    Understand injection timing →
